# Deploying Divine Frank Realty on Vercel

1. Create a new Vercel project and choose **Upload**.
2. Upload the contents of this project (the folder containing `index.html`), or use the supplied Vercel ZIP.
3. Leave the framework preset as **Other**. No build command is required.
4. Deploy.

The `assets` folder must remain alongside `index.html`; it contains every property image. Nearby amenities are automatically shown on all three property detail pages.
